# HomeBass

**A digital Gen-X clubhouse in a modern pixel world.**

HomeBass is a social, game, music, media, and community space inspired by the feeling of late-80s / 90s arcades, basements, BBS culture, video stores, mixtapes, and hanging out after dark.

This repository is being built in small, tested rungs.

## Core places

- **The Hangout** — commons / social heart
- **Last Credit** — arcade
- **AfterHours BBS** — messages, boards, door games
- **Tape Deck** — music, mixtapes, audio
- **Hot Shots** — quizzes and challenges
- **LackLuster** — video store / movie + TV culture
- **N.E.R.D.S.** — achievements and records

## Visual direction

SNES-era spirit without strict SNES-era limitations: readable pixel art, rich room lighting, restrained effects, comfortable scaling, and modern accessibility.

> HomeBass is a place first, an app second.
