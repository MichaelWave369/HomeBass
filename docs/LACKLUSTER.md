# LackLuster — Video Store Contract

LackLuster is HomeBass's video-store world.

The user-facing fiction is a rental store with shelves, staff picks, returns, membership cards, and ridiculous late-fee energy.

## v0.7 behavior

- genre filtering
- selectable VHS cases
- local rental / return state
- persistent checked-out list
- membership-card status
- Staff Picks
- reserved PHIVid and Paracut shelves
- planned watch-room surface
- responsive video-store layout

## Current media behavior

No copyrighted video is bundled.

The current tapes are fictional HomeBass fixtures plus reserved integration shelves for PHIVid and Paracut.

## Future media adapter

A video adapter may later provide:

- playable local media
- PHIVid assets
- Paracut exports
- thumbnails / cover art
- runtime metadata
- subtitle tracks
- provenance
- shared watch-room sessions
- agent commentary / hosting
- playback receipts

LackLuster should not care whether the source is local, generated, imported, or Porch-shared.

## Rental metaphor

"Renting" is a HomeBass interaction metaphor.

It may later represent:
- pinning something to a watch queue
- temporarily syncing a Porch-shared asset
- opening a licensed stream
- reserving a local copy
- joining a scheduled watch room

The store fiction remains stable while the media plumbing changes.

## Rights rule

HomeBass should never imply that a locally discovered or remotely shared media asset is licensed merely because it appears on a shelf.

Rights / availability metadata must remain separate from the nostalgic presentation layer.
